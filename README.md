# Posted Up Produce

Order site for Posted Up Produce: personal shopping at Chicago farmers markets, with meet-up pickup and Wednesday delivery.

- `index.html` is the whole site (menu, order form, order terms).
- Orders post to a Google Apps Script web app that writes to the "Posted Up Produce Orders" Google Sheet. Set `ORDER_ENDPOINT` in `index.html` to the web app URL.
- Hosted with GitHub Pages from the `main` branch.
